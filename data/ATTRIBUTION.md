# Destination seed data attribution

The partial Indonesia seed file uses the Audiala Places Indonesia subset from the 2026-09-28 release under CC BY 4.0. Required credit: “Data by Audiala — https://audiala.com”.

Coordinates are refreshed from Wikidata structured data under CC0. Each record retains a Wikidata item URL. Image URLs, ratings, ticket prices, opening hours, addresses, and descriptions are blank unless a permitted source is added later.

This file is a partial seed, not a comprehensive list of Indonesian destinations. The upstream source explicitly describes its coverage as non-exhaustive.
